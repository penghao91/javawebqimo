🎨 问卷系统 CSS 样式统一修复对比

⚠️ 发现的主要问题：
  • 导航栏高度不一致，滚动时产生页面抖动
  • 页面顶部间距存在重复定义（88px 和 96px 混用）
  • 头部卡片和侧边栏卡片尺寸不统一
  • 每个 JSP 文件都有完整的 CSS 定义，代码重复严重
✅ 修复方案：
  • 创建 common-styles.jsp 统一样式文件
  • 标准化所有关键尺寸值
  • 添加平滑过渡效果，减少视觉跳动
  • 改进响应式设计

📊 关键尺寸标准化对比

元素 属性 修复前 修复后 状态
.navbar height 不固定 / 使用 padding 76px（固定） 已修复
.navbar padding 0.75rem / 0.4rem 0（使用 flex 居中） 已修复
.page-wrapper padding-top 88px / 96px（不统一） 96px（统一） 已修复
.design-header-inner padding 18px 22px 24px 28px 已统一
.design-header-inner min-height 无或不一致 136px 已统一
.nav-card padding 14px 14px 10px 24px 20px 已统一
.nav-card min-height 无 360px 已统一
.content-card min-height 无 400px 已统一

📁 文件结构改进

修复前：

questionnaire/ ├── list.jsp (包含完整 CSS，约 800 行) ├── form.jsp (包含完整 CSS，约 500 行) ├── folders.jsp (包含完整 CSS，约 1000 行) ├── design.jsp (包含完整 CSS，约 600 行) └── _head.jsp (未被使用) 问题 CSS 重复，维护困难

修复后：

questionnaire/ ├── common-styles.jsp (统一的 CSS 样式，约 600 行) ├── _head.jsp (引入 common-styles.jsp) ├── list.jsp (仅页面特定样式) ├── form.jsp (仅页面特定样式) ├── folders.jsp (仅页面特定样式) └── design.jsp (仅页面特定样式) 改进 CSS 集中管理，易于维护
